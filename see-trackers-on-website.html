How to see which trackers a website uses

Most websites load code from companies you've never heard of: ad networks, analytics tools and data brokers. Each one can record that you visited. Here's how to see who they are.

The quick way: an extension

  1. Install Fine Print Guard (free).
  2. Open any website.
  3. Click the Fine Print Guard icon and open the Protection tab. It shows how many tracking companies the page tried to load, names them, and says how many it blocked.
  4. For the full list, open the report and download it as PDF, Excel or CSV.

All of this happens on your computer. Fine Print Guard doesn't send the sites you visit to any server.

The manual way: Chrome's developer tools

  1. Right-click the page and choose Inspect.
  2. Open the Network tab and reload the page.
  3. Look at the Domain column for addresses that aren't the site's own.

This shows everything, but you have to know which domains belong to trackers. The extension does that matching for you, against nearly 1,000 known ad, analytics and data-broker domains.

Stopping them

Fine Print Guard blocks those trackers by default. If it breaks something you need, pause blocking on that site with one click.

Questions

Are all third-party scripts trackers?

No. Many are harmless, like fonts or video players. Fine Print Guard names the known ad, analytics and data-broker companies and lists other outside companies separately.

Does seeing the trackers send my data anywhere?

No. The check runs on your computer.

Yes. Every feature is free, with no account.
