Install Fine Print Guard in 2 minutes

It's free and there's no account to make.

1. Add it to Chrome

  1. Open the Fine Print Guard page in the Chrome Web Store.
  2. Click Add to Chrome, then Add extension.

2. Turn it on for all sites

A welcome page opens by itself. Click Allow on all sites and accept Chrome's prompt. This lets it block ads and read each site's terms everywhere, not just when you click it.

If you skip this, it still works: click its icon on any page to check that page.

3. Pin it to your toolbar

  1. Click the puzzle-piece icon at the top right of Chrome.
  2. Click the pin next to Fine Print Guard.

Now you'll see each site's grade right on the icon.

Done
